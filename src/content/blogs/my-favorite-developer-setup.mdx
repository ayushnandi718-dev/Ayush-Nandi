# My Favorite Developer Setup (2026)

Your setup shouldn't be a hobby — it should be a multiplier.

## Hardware

- **Laptop** — something fast enough to never be the bottleneck
- **A second monitor** — one screen for code, one for everything else
- **Mechanical keyboard** — because you'll type a million times a day

## Software

- **VS Code** — with a theme I don't get tired of and a font that's easy to read
- **Zsh + a good terminal** — because the CLI is home
- **Git** — daily. Not weekly, daily

## Browser Extensions

The right extensions save hours:

- **Dark reader** — for the code that fights the theme
- **DevTools shortcuts** — navigation without leaving the keyboard
- **A clipboard manager** — never lose a command again

## The Point

None of this makes you a better developer by itself.

But removing friction from your workflow means more time in the flow — and that's where the good code happens.
